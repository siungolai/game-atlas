# 深空当铺 · 酿酒合成谱

对应 Steam 创意工坊「[酿酒拓展 | Brewing Expansion](https://steamcommunity.com/sharedfiles/filedetails/?id=3829730904)」，所属 **Outer Ring District**（外环区）。

零依赖的独立页面，字体随仓库分发，双击 `index.html` 即用。

**线上**：<https://siungolai.github.io/game-atlas/深空当铺/>

## 收录

8 页残卷、51 条酒谱、17 味材料、4 类失败产物，外加模组里的 67 款酒文案与 17 味材料说明。

其中 12 款**藏品酒**没有固定配方，单独列在谱录末尾，不参与合成判定。

## 功能

- **合成判定**：两份材料下锅，命中酒谱出名；落空按材料所属域给出失败产物（凡间→杂酿、远来→异调、情思→错付、遗光→余烬）
- **顺序无关**：两味材料互换得出同一杯酒，槽间 `⇄` 可随时对调
- **三种填入模式**：自动轮填 / 只改左槽 / 只改右槽，连续试配方时少点一次
- **全谱检索**：酒名、材料、残卷名都能搜，另可按残卷筛选；连酒的官方风味文案一起检索
- **兼容提示**：选了一味之后，另一槽会高亮所有能配的材料
- **官方文案**：合成出结果时显示这款酒的来历，选中材料时显示它的说明
- **藏品酒**：12 款无配方酒单列成区，默认折叠
- **双主题**：默认深空夜色，可切日间

## 数据来源

游戏内酿酒系统的 8 页残卷截图（失败手札、凡间单酿、凡间双穗、远来之酿、远凡交汇、双远合酿、情思手记、遗光残页），逐条录入。

配方与文案另与工坊模组《酿酒拓展》3.6.7.4 的本地化文件 `Localization/zh.csv` 逐条核对：8 页残卷原文一致；「远凡交汇」的落款据此补为「——一个从远方来，一个从近处生。」，此前页面写的是「落款残佚。」。67 款酒的官方风味文案、17 味材料的说明同样取自该文件。

模组原件仅作本地留档放在 `Modlist/`，不进仓库（`.gitignore` 已排除）。
