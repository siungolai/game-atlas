# 游戏图鉴 · Game Atlas

收录我在玩的游戏与模组的查询工具。每一份都是**零依赖的独立页面**：不连任何 CDN、不需要构建、双击就能用，字体随仓库一起分发，连同 `fonts/` 拷走即可离线运行。

**线上地址**：<https://siungolai.github.io/game-atlas/>

## 目录结构

```
game-atlas/
├── index.html          # 工具索引页（新工具在这里挂一张卡片）
├── fonts/              # 自托管字体子集：Noto Serif SC / Noto Sans SC / Ma Shan Zheng
├── tools/              # 字体子集生成 + 离线可用性校验
├── 深空当铺/            # 一个游戏一个目录
│   ├── index.html      # 该游戏的工具页（可直接访问 /深空当铺/）
│   ├── Modlist/        # 模组原件留档（不进仓库，.gitignore 已排除）
│   └── README.md       # 该工具的说明
└── README.md           # 本文件
```

**加新游戏的方式**：在根目录新建一个文件夹（游戏名或模组名均可），把做好的 `index.html` 放进去，再回到根 `index.html` 复制一张卡片改成新内容即可。索引页里有一行注释标出了卡片的起止位置。

## 深空当铺 · 酿酒合成谱

对应 Steam 创意工坊「酿酒拓展 | Brewing Expansion」，所属 **Outer Ring District**（外环区）。

**收录**：8 页残卷、51 条酒谱、17 味材料、4 类失败产物，外加模组官方的 67 款酒文案与 17 味材料说明；其中 12 款藏品酒没有固定配方，单列成区。

**功能**：

- 双材料合成判定 —— 命中酒谱出名，落空按材料域给出失败产物（凡间→杂酿、远来→异调、情思→错付、遗光→余烬）
- 材料**不分先后**，两张配方表互换算同一组，`⇄` 可随时互换左右槽
- 三种填入模式：自动轮填 / 只改左槽 / 只改右槽，配材料时少点一次
- 全谱检索（酒名、材料、残卷都能搜，连酒的官方文案一起检索）+ 按残卷筛选
- 兼容性实时提示：选了一味材料后，另一槽高亮所有可配材料
- 合成出结果时显示这款酒的来历，选中材料时显示它的说明
- 12 款藏品酒单列成区，默认折叠，检索命中时自动展开
- 深浅两套主题，默认深空夜色

## 本地使用

clone 或下载后，直接双击 `index.html` 打开即可，不需要任何服务器。

字体从 `fonts/` 读取，**不要只拷走单个 HTML 文件**，否则标题会回退成系统字体。

## 维护

改文案后如果出现子集里没有的字，重新生成字体子集：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build-fonts.ps1
```

该脚本依赖 Python 与 `fonttools`、`brotli`，先装依赖：`python -m pip install fonttools brotli`。它会把字符集切成 600 字一块分别请求 Google Fonts，再用 fontTools 合并成单个 woff2 —— 单次请求超过约 800 字时，css2 的 `text=` 参数会静默失效并退回整套 unicode-range 切片，脚本对此有断言。

提交前跑一次离线校验（外部引用、字符覆盖、字体体积三项）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\check-offline.ps1
```
